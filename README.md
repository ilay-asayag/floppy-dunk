# Floppy Dunk — play in your browser

**Play: https://ilay-asayag.github.io/floppy-dunk/**

Flap a basketball and drop it down through every hoop. Tap (or click, or `Space`) to hop up and forward; between taps the ball flies on its own arc and bounces off the rim ends.

- **Clean** (no rim touch) scores 2, a make that touched the rim scores 1, a high clean adds +1, and from the third clean in a row every make counts double.
- **One ball:** fly past a hoop without dropping through it, or touch the rooftop wall, and the run is over.

A Play Perfect prototype. This repository contains only the compiled Unity WebGL build.
